# Case 4 run sheet

1. New task; upload **every** file in `data/raw/public_reuse_check/fastq/<run>/` (do not leave any out, do not rename).
2. Paste the request exactly as written below.
3. Read the plan. Approve it or reject it; do not edit it.
4. Output folder: `results/public_reuse_check/<run>/`.
5. Fill in the record's row in `run_log.tsv` (outcome: executed / blocked / plan_invalid / execution_failed / rejected; for anything other than executed, copy PaleoRigor's message verbatim).
